ElvadoPress API

Version 1.1 · Datei-basiertes CMS unter /cms/

Öffentliche, lesende Konfiguration

GET /cms/api.php?action=public

Liefert die aktuelle site.json-Konfiguration ohne Zugangsdaten. Die Live-Website nutzt genau diesen Endpunkt.

Geschützte Verwaltungs-API

/cms/api.php?action=...

Schreibende Aufrufe benötigen X-ElvadoPress-Token aus dem lokalen CMS-Login. Details stehen in API.md.
